Neurovia

An IoT-enabled tangible rehabilitation system that connects physical activities, embedded hardware, and therapist-facing data analytics.

IoTEmbedded systemsRFIDCapstone project

From tangible input to useful feedback

Neurovia was designed to support cognitive and motor rehabilitation for elderly users through structured, trackable activities. The system turns interaction with RFID-tagged shapes into session data that therapists can review.

The project brought together hardware assembly, microcontroller programming, RFID input, data handling, and a responsive web dashboard into one working prototype.

Role
System design and development
Platform
ESP32-S3 and web dashboard
Core input
12 RFID-tagged shapes and 4 readers
Output
Session performance data

System breakdown

Problem
Rehabilitation activities can be difficult to track consistently when physical interaction and progress data are separated.
Approach
Built a tangible activity platform with RFID readers, an ESP32-S3 controller, and a therapist-facing analytics dashboard.
Engineering focus
Reliable device input, embedded control, data transfer, interface clarity, and structured testing.
Result
A functional prototype that records interaction and session performance for review and supports repeatable cognitive and motor training.
